      What you can do here

      Layerwright connects this Figma file to the Claude Code, Codex and Cursor sessions on your computer. Ask a session in its chat to import a design, build a screen or change one, and it works here. You can also send it work from this window.

      The tabs

      HomeYour selection and who gets it. Select layers in Figma, pick a session under Send to, then press an action, or write your own request in the box. Build in code implements it with your components, Polish design critiques and fixes it, Make component turns it into a component, Mobile version builds a phone layout next to it. Click the picture to zoom to the layer.
      ActivityYour requests: progress, the session’s answer, and Stop. Below, In Figma lists what sessions built or changed, with a way to show each result.
      SkillsGuidance a session reads before a job: design critique, UX copy, accessibility, layout and more. Turn each one on or off, or add your own from a link or pasted text.
      SettingsThe AI cursor (a session’s cursor while it changes the canvas), zooming to the result, starting Claude Code on its own, pairing with this computer, and the port.
      SessionsThe sessions connected now, what each is doing, and how many requests it is on. Remove one with ✕ (it asks once more).

      More ways in

      Notes on the canvasType a text layer that starts with @ and a session’s name on the frame it’s about, for example @Checkout make this responsive, or @claude when one session is connected. It goes once you stop typing, and the answer appears under it.
      Compact windowThe arrows button next to Star shrinks this window to the selection, the actions and the chat box.
      In your agent/layer:help in Claude Code or Codex lists every command. Something not working? Run npx layerwright doctor in your project.
